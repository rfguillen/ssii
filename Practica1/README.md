# Práctica 1 · Algoritmo genético para N reinas

Estudio de un algoritmo genético aplicado al problema de colocar N reinas en un tablero evitando conflictos entre ellas.

## Contenido

- `Practica1.exe`: ejecutable de la entrega para Windows.
- [Practica1.pdf](Practica1.pdf): explicación del algoritmo, pruebas de ajuste, manual y validación.
- [Casos de Validación](Casos%20de%20Validaci%C3%B3n/README.md): archivos utilizados para estudiar distintas dimensiones del problema.

## Qué se estudia

La memoria aborda la configuración del algoritmo genético, los operadores de cruce y mutación, las pruebas de ajuste y el comportamiento global de la búsqueda.

## Uso

Ejecuta `Practica1.exe` en Windows y sigue el manual incluido en la memoria para proporcionar los parámetros y los casos.

## Nota

Calificación: **7,5/10**.
