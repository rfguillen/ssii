Para compilar el código fuente se recomienda utilizar CodeBlocks 20.03, ya que incluye un compilador con soporte completo para C++11, estándar requerido por las funcionalidades utilizadas.
Pasos para compilar:
1. Abrir CodeBlocks 20.03
2. Abrir el archivo del código fuente:
	File -> Open -> Seleccionar sbr-fc.cpp
4. Asegurarse de que el estándar del compilador es C++11 o superior:
	Settings -> Compiler -> Compiler Flags -> Enable C++11 (por si acaso no está activado por defecto)
5. Compilar con Build:
	Build -> Build
6. Para seguir con la ejecución se recomienda ver el documento "Manual de Uso del Software.pdf"
